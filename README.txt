HOKTO Mushroom New Year Omikuji - Share Version

This version keeps the supplied 4-frame box animation and 9 fortune images.
It adds a Share My Fortune popup with:
- Native phone sharing (More)
- WhatsApp
- Facebook
- X
- Telegram
- Copy Link

The page background is completely transparent so the game can be embedded in WordPress with an iframe.

WordPress iframe:
<iframe
  src="https://zyeichuu.github.io/omikuji-game/"
  width="700"
  height="1050"
  frameborder="0"
  scrolling="no"
  style="width:700px;max-width:100%;height:1050px;border:0;background:transparent;display:block;"
  title="Omikuji Fortune Game"
  allow="clipboard-write"
></iframe>

After replacing your GitHub files, commit and push them. GitHub Pages will update the same URL.
